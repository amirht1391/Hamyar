# همیار (Hamyar)

[English](README.md) · **فارسی**

یک برنامهٔ دسکتاپ آرام و مینیمال برای دانش‌آموزان و دانشجویان ویندوز: **برنامه‌ریزی** روزانه با آلارم زنجیره‌ای، **جدول‌های آلارم** خودتان، بخش **مطالعه** با برنامهٔ دقیق مرور، **فلش‌کارت**، **جدول هفتگی**، **اوقات شرعی**، **امتحان‌ها** و **حالت تمرکز** تمام‌صفحه.
فارسی / انگلیسی، تم تیره / روشن، چهار رنگ اصلی و ظاهر شیشه‌ای. داده‌ها فقط روی رایانهٔ خودتان در SQLite ذخیره می‌شوند و جایی فرستاده نمی‌شوند.

## امکانات اصلی
- **برنامه‌ریزی** - روز به‌شکل زنجیره‌ای از ردیف‌ها (عنوان، شروع، دقیقه، توضیحات). با تغییر یک ساعت همهٔ ردیف‌ها جابه‌جا می‌شوند. برنامه‌های ذخیره‌شده با تاریخ، تاریخ روز بعد برای ردیف‌های بعد از نیمه‌شب، بی‌صدا کردن هر ردیف، **افزودن ردیف در هر جای جدول** (به‌صورت ردیف اضافه که چیزی را جابه‌جا نمی‌کند، یا داخل زنجیره)، **گروه‌های رنگی** (پالت بزرگ + انتخاب‌گر رنگ)، خروجی ورد (A5، تا ۳۵ ردیف در یک صفحه).
- **آلارم‌ها** - جدول‌های آلارم خودتان، کشیدن آلارم بین جدول‌ها، تکرار (یک‌بار / روزانه / روزهای کاری / هفتگی)، صدا و کار (باز کردن فایل، برنامه یا لینک، اجرای دستور، نمایش پیام).
- **مطالعه** - مبحث‌ها با خط زمانی دقیق مرور که با نزدیک‌شدن امتحان فشرده‌تر می‌شود.
- **فلش‌کارت** - پنج جعبهٔ لایتنر، ویرایش سریع، کشیدن و رها کردن، کارت‌های برگردان سه‌بعدی، ورود و خروج CSV.
- **جدول هفتگی، اوقات شرعی، امتحان‌ها، جلسات تمرکز** (تایمر، چک‌لیست، یادداشت، تختهٔ نقاشی، ماشین‌حساب).
- **میان‌بُرهای صفحه‌کلید** - پیش‌فرض‌ها (Ctrl+1 تا Ctrl+9 برای صفحه‌ها، F1 راهنما و...) و **میان‌بُر دلخواه**: هر ترکیب کلید را به یک فایل، برنامه یا سایت وصل کنید (تنظیمات ← میان‌بُرهای صفحه‌کلید).
- **راهنمای عملی** - در اولین اجرا یک نشانگر در همهٔ بخش‌ها می‌چرخد و هرکدام را توضیح می‌دهد. هر وقت خواستید از بخش راهنما یا با `Ctrl+Shift+H` دوباره ببینید.
- پشتیبان‌گیری (خودکار روزانه + دستی)، حالت امن، جابه‌جایی تب‌ها با کشیدن، انیمیشن‌های نرم.

## میان‌بُرهای پیش‌فرض
| کلیدها | کار |
|---|---|
| Ctrl+1 تا Ctrl+9 | خانه، برنامه‌ریزی، آلارم‌ها، مطالعه، فلش‌کارت، جدول هفتگی، اوقات شرعی، امتحان‌ها، تنظیمات |
| F1 | راهنما |
| Ctrl+Shift+S | شروع جلسهٔ تمرکز |
| Ctrl+Shift+H | راهنمای عملی |

همه را می‌توان در تنظیمات عوض کرد. حرف‌های ساده هیچ‌وقت میان‌بُر را اجرا نمی‌کنند (Ctrl یا Alt لازم است؛ کلیدهای F تنها هم کار می‌کنند).

## ساخت برنامه
پیش‌نیاز: ویندوز ۱۰ یا ۱۱ و [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0). فونت‌ها در مخزن هستند (پوشهٔ `Fonts/`، وزیرمتن) و داخل exe جاسازی می‌شوند.
```powershell
git clone <آدرس-مخزن-شما>
cd Hamyar
dotnet restore
dotnet build -c Release
dotnet run -c Release
```
ساخت یک exe نهایی:
```powershell
.\publish.ps1                  # کم‌حجم، به .NET 8 Desktop Runtime نیاز دارد
.\publish.ps1 -SelfContained   # حدود ۷۰ مگابایت، همه‌جا اجرا می‌شود
```
خروجی: `publish\Hamyar.exe`.

## داده‌ها و گزارش خطا
`%AppData%\TaskAlarm` - شامل `data.db`، پوشهٔ `backups` و `log.txt` (نام پوشه عمداً قدیمی مانده تا با به‌روزرسانی داده‌ای از دست نرود).
اگر اجرای برنامه به‌پایان نرسد، اجرای بعدی در **حالت امن** است (بدون شیشه، با فونت سیستم)؛ از تنظیمات خاموشش کنید.

## ساختار پروژه
| فایل | نقش |
|---|---|
| `App.xaml(.cs)` | استایل‌ها، بارگذاری فونت، گزارش خطا |
| `MainWindow*.cs / .xaml` | پنجرهٔ اصلی، هر صفحه در یک فایل |
| `Hotkeys.cs` | میان‌بُرها (پیش‌فرض و دلخواه) و کارت تنظیمات آن‌ها |
| `Tour.cs` | راهنمای عملی اولین اجرا |
| `PlanGroups.cs`، `ColorPickerPanel.cs` | گروه‌های رنگی برنامه‌ریزی و انتخاب‌گر رنگ |
| `PlanDocx.cs` | خروجی ورد (docx دست‌نویس، بدون بستهٔ اضافه) |
| `Db.cs`، `Cfg.cs`، `Models.cs` | SQLite و تنظیمات |
| `Loc.cs` | متن‌های فارسی / انگلیسی |
| `Fonts/` | وزیرمتن (همهٔ ضخامت‌ها) + `OFL.txt` |
| `ReviewEngine.cs`، `Study.cs`، `Scheduler.cs` | مرور فاصله‌دار و آلارم |

## فونت و مجوز
برنامه از **وزیرمتن (Vazirmatn)** در چند ضخامت استفاده می‌کند (Regular برای متن، SemiBold / Bold / ExtraBold برای عنوان‌ها). فایل‌های فونت در پوشهٔ `Fonts/` با مجوز [SIL Open Font License 1.1](Fonts/OFL.txt) منتشر شده‌اند. خروجی ورد با فونت **Arial** ساخته می‌شود تا روی همهٔ رایانه‌ها یکسان دیده شود.
کد برنامه با [مجوز MIT](LICENSE) منتشر شده است.
